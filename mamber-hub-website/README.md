# Mamber Hub Website

Modern responsive landing page for the Mamber Hub app.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Important placeholders to replace before launch

- WhatsApp link in `src/main.jsx`
- Real Android Play Store / APK link
- Actual Mamber Hub logo asset
- Real app screenshots
- Final membership pricing
- Privacy Policy and Terms & Conditions pages
- Real social media links

The UI is intentionally built around the Mamber Hub app and can later be connected to Firebase or a web login.
